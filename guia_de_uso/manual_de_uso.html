1. Introducción y acceso

Yarumito Schedule es la plataforma de la I.E. Rural Yarumito para administrar docentes, catálogos académicos (sedes, aulas, turnos, grados, áreas, asignaturas), planes de estudio, asignación de carga académica y construcción de horarios con validación automática de conflictos.

Cómo se abre

ServicioDirección
Aplicación web (frontend)http://localhost:5173
API (backend)http://localhost:8080
Base de datos PostgreSQLlocalhost:5432

Para levantar todo: docker compose --profile app up --build. Para cargar docentes de demostración: docker compose --profile seed run --rm seed.

Credenciales de desarrolloCorreo rector@yarumito.edu.co · Contraseña según la variable APP_SEED_PASSWORD del archivo .env (en README.md figura el valor por defecto de desarrollo).
Rol único en la prácticaExisten los roles RECTOR y DOCENTE, pero hoy cualquier usuario autenticado accede a todas las pantallas. Solo existe un usuario (el Rector) y no hay pantalla para crear más.

2. Conceptos y orden de trabajo recomendado

Glosario

TérminoSignificado
Año lectivoPeriodo escolar (p. ej. 2029). Estados: Planeación → Activo → Cerrado. Solo uno puede ser «actual».
SedeLugar físico. Solo una puede ser la principal.
AulaEspacio de una sede (Aula, Laboratorio, Sala de sistemas, Cancha) con capacidad.
TurnoJornada: Mañana o Contrajornada (únicos nombres admitidos). Define duración de clase, clases por día y descanso.
Franja horariaCada bloque (clase o descanso) dentro de un turno.
Grado / GrupoGrado = nivel 6° a 11°. Grupo = curso concreto de un grado en un año y una sede (p. ej. 1001).
Plan de estudiosAsignaturas e intensidad semanal de cada grado en un año.
IdoneidadHabilitación de un docente para un área o asignatura (Principal / Autorizada / Excepcional).
Asignación académicaDocente + grupo + asignatura + horas por semana. Nace en Borrador y se Confirma.
Clase programadaUna hora de una asignación ubicada en día + franja + aula.

Orden recomendado (de lo general a lo particular)

Año lectivo→Sedes→Aulas→Turnos→Franjas→Grados→Áreas/Asignaturas→Plan de estudios→Grupos→Docentes + títulos + idoneidades→Restricciones→Asignación→Horario→Validaciones

El menú lateral sigue este orden. Cada pantalla depende de los datos de las anteriores: sin franjas no hay horario; sin plan de estudios no hay asignaciones; sin docentes con idoneidad no se puede asignar.

Convenciones de pantalla

  • Botones principales a la derecha del encabezado (+ Nuevo…). El lápiz verde de cada fila abre la edición.
  • Los formularios se abren en ventanas modales; los errores del servidor aparecen dentro de la modal.
  • Los nombres de sedes se guardan en MAYÚSCULAS.
  • Tema claro/oscuro: lo toma del sistema operativo.

3. Inicio y cierre de sesión

/admin
  1. Abre http://localhost:5173; te redirige a /admin si no hay sesión.
  2. Escribe el Usuario (correo electrónico) y la Contraseña; puedes ver/ocultar la contraseña con el ícono del ojo.
  3. Marca Recordarme si quieres conservar la sesión al cerrar el navegador.
  4. Pulsa Iniciar sesión.

La sesión dura 8 horas (token JWT). Si expira, la plataforma te devuelve al formulario.

Ejemplo. Correo rector@yarumito.edu.co + contraseña correcta → entras al panel. Con una contraseña errónea aparece «Error de autenticación» y no avanzas.

Cerrar sesión: menú lateral → Cerrar sesión. (El ítem Perfil del menú no abre ninguna pantalla actualmente.)

4. Panel principal (Inicio)

/dashboard

Muestra un saludo, cuatro tarjetas de resumen y tarjetas de módulos con el botón Abrir módulo (Gestión de docentes, Gestión académica, Año lectivo y grupos, Restricciones, Asignación, Construcción del horario, Validaciones, Publicación, Auditoría, Consultas, Informes).

AtenciónLas cifras de las tarjetas (p. ej. «12 docentes») son valores fijos de demostración y no reflejan la base de datos real. Para cifras reales usa Docentes o Informes.

5. Año lectivo y configuración institucional

Este bloque prepara la «infraestructura» del colegio. Se hace una vez y luego se ajusta.

5.1 Sedes

/dashboard/sedes

Ver y buscar

Tabla con Código, Sede, Dirección, Principal y Acciones. El cuadro Buscar sede filtra por código, nombre o dirección.

Crear

  1. + Nueva sede.
  2. Completa Nombre de la sede, Código, Dirección y marca si es sede principal.
  3. Guardar.
Ejemplo. Nombre «Sede Vereda El Roble», código ROB-01, dirección «Vereda El Roble km 4», principal: No → aparece como «SEDE VEREDA EL ROBLE».

Editar

Lápiz de la fila → cambia nombre, código, dirección o principal → Guardar.

Reglas

  • Código único (409 «Ya existe una sede con ese código»).
  • Solo una sede principal (409 «Ya existe una sede principal registrada»). Para cambiarla, primero edita la actual y desmárcala.
  • No hay botón de eliminar sedes.

5.2 Aulas

/dashboard/aulas

Elige primero la Sede en el selector; se listan sus aulas (Nombre, Tipo, Capacidad, Estado).

Crear

  1. + Nueva aula.
  2. Sede, Nombre del aula (ej. A-101), Tipo (Aula, Laboratorio, Sala de sistemas, Cancha), Capacidad (opcional).
  3. Guardar.

Editar vs. Nueva versión

  • Editar (lápiz): corrige capacidad, nombre o estado activa/inactiva del mismo registro.
  • Nueva versión: úsala cuando el aula cambia de nombre, tipo o sede. Crea un aula nueva activa y deja la anterior Inactiva, conservando el historial.
Ejemplo. El aula «A-101» (Aula, 40) se convierte en laboratorio: pulsa Nueva versión, cambia el tipo a Laboratorio. Quedan «A-101 Laboratorio · Activa» y «A-101 Aula · Inactiva».
No se eliminaEl borrado físico de aulas es rechazado por el sistema (409): inactívalas.

Regla: no puede haber dos aulas activas con el mismo nombre en una sede.

5.3 Turnos

/dashboard/turnos

Define las jornadas. Campos: Nombre del turno (solo Mañana o Contrajornada), Hora de inicio, Hora de finalización, Duración de la clase (min), Clases por día, Clases antes del descanso, Descanso (min).

Ejemplo. Mañana · 07:00–13:00 · clase 55 min · 6 clases/día · 3 antes del descanso · descanso 30 min.
  • Editar con el lápiz. Buscador por nombre.
  • La hora de inicio debe ser anterior a la de fin.
  • Un nombre distinto de los dos permitidos hace fallar el guardado (ver sección de limitaciones).

5.4 Franjas horarias

/dashboard/franjas

Elige un Turno y arma su secuencia de clases y descansos. Tabla: Orden, Número, Horario, Tipo (Académica/Descanso), Horas.

Crear

  1. + Nueva franja.
  2. Turno, Número (de clase; 0 para descansos), Hora de inicio/fin, Orden en el día, Horas académicas equivalentes (1 por clase, 0 por descanso), y marca Esta franja es un descanso si aplica.
Ejemplo (turno Mañana).
Orden 1  Nº1  07:00-07:55  Académica  1 h
Orden 2  Nº0  07:55-08:25  Descanso   0 h
Orden 3  Nº2  08:25-09:20  Académica  1 h
Orden 4  Nº3  09:20-10:15  Académica  1 h
  • Las franjas del mismo turno no pueden solaparse (400).
  • La duración debe coincidir con la del turno.
  • Los descansos no se pueden programar con clases.

5.5 Grados

/dashboard/grados

Registra los grados de 6° a 11°. Solo se elige el nivel; el servidor calcula nombre (SEXTO…UNDÉCIMO), tipo (Básica o Media), prioridad de asignación y horas semanales esperadas (30 h básica, 37 h media).

Ejemplo. + Nuevo grado → nivel 8 → queda «Octavo · Básica · prioridad 3 · 30 h».
CuidadoEl sistema actualmente permite crear dos veces el mismo nivel (ver informe de hallazgos). Verifica antes de crear.

5.6 Año lectivo y grupos

/dashboard/anio-lectivo

Años lectivos

  • Crear año: Año (ej. 2029), Fecha de inicio, Fecha de finalización, Estado (Planeación o Activo). La fecha de inicio debe ser anterior a la de fin.
  • Editar fechas: no permitido si el año está Cerrado.
  • Activar año: pasa de Planeación a Activo y lo marca como «Año actual». Solo puede haber uno actual (409 si ya existe otro).
  • Cerrar año: Activo → Cerrado (irreversible; conserva el histórico).
  • Transiciones válidas: Planeación → Activo → Cerrado. Cualquier otra se rechaza.
Parámetros automáticosAl crear un año se generan HORAS_DOCENTE_SEMANALES = 22 y MAX_HORAS_EXTRA = 10 para ese año.

Grupos

  1. Selecciona el año lectivo.
  2. + Agregar grupo: Código del grupo (el sistema sugiere el siguiente, p. ej. 1001), Grado, Año lectivo, Sede, Cantidad de estudiantes, Estado, y opcionalmente Aula habitual y Director de grupo.
  3. Filtra por grado, sede y estado con la barra de filtros.
Ejemplo. Código 1001, Grado Décimo, Año 2029, Sede Principal, 30 estudiantes, Activo.

Código único por año (409). Si la cantidad de estudiantes supera la capacidad del aula fija, se muestra una advertencia logística.

6. Áreas y asignaturas

/dashboard/areas

Arriba el listado de Áreas (Código, Área, Clasificación obligatoria/opcional, Aplicación todos los grados/solo media, Estado). Al seleccionar un área aparece abajo la lista de sus Asignaturas.

Áreas

  • + Nueva área: Nombre, Código, Área obligatoria, Solo para Media, Estado. También hay un selector «Área del catálogo» para partir de las áreas oficiales precargadas.
  • Lápiz = editar. Botón de activar/desactivar (con modal de confirmación). Filtros: texto y Estado (Todas / Activas / Inactivas).

Asignaturas

  • + Nueva asignatura (o elegirla del catálogo): Área, Nombre, Código, Abreviatura, Color de identificación, Máximo de clases consecutivas (por defecto 2), Tipo de aula requerida, y los interruptores Exige idoneidad estricta, Asignatura de Media Técnica, Requiere docente exclusivo, Estado.
Abreviatura restringidaLa abreviatura solo puede ser una de la lista institucional (MAT, MATE, CAST, INGL, FISI, QUIM, BIOL, EDFI, INFO, ETIC, RELI, ARTE, etc.). Una abreviatura fuera de lista produce un error genérico del servidor. Usa el catálogo para evitarlo.
Ejemplo. Área «Matemáticas» (MAT) → asignatura «Geometría», código GEO, abreviatura GEOM, máx. 2 clases consecutivas, aula tipo Aula.

Desactivar un área/asignatura la oculta de los selectores sin borrar el histórico.

7. Plan de estudios

/dashboard/plan-estudios
  1. Elige Año lectivo y Grado. Aparece el Resumen del grado: tipo, horas esperadas, horas configuradas, diferencia y una barra «X de Y h configuradas».
  2. + Agregar asignatura → selector por Área y Asignatura, Horas semanales, Turno y Observación.
  3. Lápiz para editar horas, turno u observación.
Ejemplo. 2029 · Décimo → Álgebra, 5 h, turno Mañana. Resumen: «5 de 37 h configuradas · Pendiente 32 h».
  • Una asignatura no se puede repetir en el mismo grado y año (409).
  • El turno elegido determina qué franjas usará el horario del grupo.
  • Años cerrados quedan en solo consulta.
Quitar asignaturaEl botón de quitar abre una ventana de confirmación pero no elimina el registro (no existe esa operación en el servidor).

8. Docentes

/dashboard/docentes

Cuatro tarjetas (total, activos, en licencia, retirados), búsqueda por nombre/apellido/documento y filtros por Área, Estado, Tipo de vinculación; botón Limpiar filtros. Tabla con Documento, Docente, Área, Vinculación, Contacto, Estado, Títulos, Idoneidad y acciones (editar ✎ y ver perfil 👤). Paginación con «Filas por página».

Botones superiores: Actualizar listado y Registrar docente.

8.2 Perfil del docente: títulos, idoneidades y estado

/dashboard/docentes/:id

El perfil reúne datos personales, institucionales, estado, títulos, idoneidades y resumen de disponibilidad semanal.

Estado administrativo

Sección «Estado»: cambia entre Activo, Licencia y Retirado. Pasar al mismo estado se rechaza (409 «ACTIVO a ACTIVO»).

Títulos profesionales

  1. Agregar título: Nivel (Normalista, Licenciatura, Profesional, Especialización, Maestría, Doctorado), Nombre del título, Institución, Año de graduación, Soporte académico (nombre de archivo).
  2. Editable con el lápiz.
Ejemplo. Licenciatura · «Licenciatura en Matemáticas» · Universidad de Antioquia · 2018.

Idoneidad académica

  1. Agregar idoneidad: Tipo (Principal, Autorizada, Excepcional), Área y/o Asignatura, Título de soporte, Justificación (obligatoria si es Excepcional), Vigente desde y Vigente hasta.
  2. Finalizar vigencia: pide una fecha de finalización; la idoneidad deja de ser válida desde esa fecha.
Ejemplo. Principal · Área Matemáticas · soporte «Licenciatura en Matemáticas» · desde 2020-01-01 sin fecha final → el docente puede recibir cualquier asignatura de Matemáticas.
Por qué importaLa asignación académica exige una idoneidad vigente para la asignatura (por el área o por la asignatura puntual). Sin ella el sistema responde «El docente no cuenta con una idoneidad vigente para la asignatura indicada».

Los títulos no tienen opción real de eliminar (el modal existe pero no hay operación en el servidor).

9. Restricciones docentes

/dashboard/restricciones
  1. Elige Año lectivo y Docente. Se muestra una tarjeta resumen y la Disponibilidad semanal: cuadrícula Lunes–Viernes × franjas del turno.
  2. Leyenda: Disponible · No disponible · Bloqueante · Preferencia · Advertencia.
  3. Pulsa una celda (o + Agregar restricción) → elige Día, Franja, Tipo (No disponible / Preferente) y Motivo.
  4. Pulsar una celda marcada abre el detalle y permite editar tipo/motivo.
Ejemplo. Docente «Ana Gómez», jueves 07:00–07:55, No disponible, motivo «Cita médica recurrente». Al intentar programarle clase ese día/franja, el horario responde «El docente tiene registrada una restricción de no disponibilidad…».
  • No disponible bloquea la programación. Preferente es solo informativa.
  • Los descansos no son editables.
  • Por ahora no se pueden borrar restricciones desde la interfaz: edítalas a «Preferente».

10. Asignación académica

/dashboard/asignacion

Dos pestañas: Asignaciones curriculares y Actividades y proyectos. Una barra recuerda la prioridad: 1) área principal → 2) idoneidades válidas → 3) transversales → 4) actividades. El Rector decide; no hay asignación automática.

Asignaciones curriculares

  1. Selecciona Año lectivo y Grupo (el grado se deriva).
  2. La tabla lista las asignaturas del plan del grado con horas, docente y estado (Pendiente / Borrador / Confirmada). Un resumen muestra horas asignadas vs requeridas.
  3. En la fila pendiente pulsa Asignar. Si procede, elige el Tipo de asignación: Principal (área de nombramiento), Idoneidad, o Transversal.
  4. Elige Docente (los de mejor encaje aparecen primero), Horas semanales y Observación. Si el docente tiene restricciones se muestra un aviso.
  5. Guardar → queda en Borrador. Pulsa Confirmar para dejarla Confirmada.
Ejemplo. Grupo 1001 · Álgebra → Asignar → Principal → Laura Rojas → 5 h → Guardar → Confirmar. Resultado: Álgebra 5 h · Laura Rojas · Confirmada.

Errores típicos

  • «Ya existe una asignación académica para el año escolar, grupo y asignatura indicados» (409).
  • «El docente no cuenta con una idoneidad vigente…» (400).

Actividades y proyectos

Carga no curricular de un docente. Pulsa Asignar → Docente, Actividad institucional (Proyecto de acompañamiento institucional, de convivencia, de emprendimiento), Horas asignadas y Justificación (obligatoria).

Ejemplo. Docente Laura Rojas · Proyecto de convivencia · 2 h · «Coordina el comité escolar».
ImportanteLos botones de editar y quitar una asignación no ejecutan ninguna acción hoy. Una asignación equivocada no se corrige desde la pantalla. Además, la pantalla no impide asignar más horas que la carga del docente (22 h + 10 extra); la validación de carga se aplica al programar clases.

11. Construcción de horario

/dashboard/horario
  1. Selecciona Año lectivo, Sede, Turno, Grupo y Vista (por grupo). A la derecha se ve el Estado del horario (Borrador / Publicado / Archivado).
  2. Tarjetas de métricas: asignaciones programadas, horas programadas/total, horas pendientes, conflictos, advertencias.
  3. La cuadrícula muestra franjas (filas) × Lunes–Viernes (columnas). Los descansos aparecen como «No programable».
  4. El panel derecho Asignaciones pendientes lista cada asignatura con sus horas por ubicar y un botón Programar.

Programar una clase

  1. Pulsa Programar en el panel o en una celda vacía.
  2. Elige Asignación académica, Día, Franja horaria y Aula (solo las activas de la sede). Se muestran Grupo, Docente, Asignatura y Horas pendientes.
  3. Guardar. La celda toma el color de la asignatura.
Ejemplo. Álgebra · Lunes · 07:00–07:55 · aula A-101 → la clase aparece en Lunes/1ª franja. Una segunda clase de Álgebra el mismo lunes en la 2ª franja es válida (máximo 2 por día).

Mover, cambiar aula o quitar

  • Pulsa una clase para ver su detalle/historial y cambiar día, franja o aula.
  • Quitar elimina la clase y devuelve la hora a «pendientes».

Reglas que bloquean (el guardado falla con mensaje)

CódigoMensaje / causa
GRUPO_OCUPADOEl grupo ya tiene clase en esa franja.
DOCENTE_OCUPADOEl docente ya tiene clase en esa franja (en cualquier grupo).
AULA_OCUPADAEl aula ya está usada en esa franja.
DOCENTE_NO_DISPONIBLERestricción «No disponible» del docente.
H-02Más de dos clases de la misma asignatura en un día.
H-07Supera la carga semanal permitida (ordinarias + horas extra).
H-08Aula inactiva o de otra sede.
H-10Horario publicado/archivado o clase bloqueada.
—«La franja seleccionada corresponde a un descanso».

Advertencias (guardan pero avisan)

  • «La cantidad de estudiantes supera la capacidad del aula» (sobrecupo).
  • Las horas por encima de la carga ordinaria se marcan como hora extra.

12. Validaciones

/dashboard/validaciones
  1. Elige el Año lectivo y el Grupo; se carga el horario y sus conflictos guardados.
  2. Tarjetas: Total, Errores, Advertencias, Resueltos, Pendientes. Un banner indica «No apto para publicación» mientras existan errores pendientes.
  3. Filtros: Severidad, Estado, Tipo de conflicto (docente ocupado, aula ocupada, sobreaforo), Grupo, Docente, Aula. Volver a validar recarga.
  4. En cada fila: Ver detalle → Marcar como resuelto.
Ejemplo. Aparece «ADVERTENCIA · Sobreaforo · La cantidad de estudiantes supera la capacidad del aula». Corrige el aula o el tamaño del grupo y marca el conflicto como resuelto.
Los intentos rechazados por el sistema (p. ej. docente ocupado) también quedan registrados como conflicto para trazabilidad.

13. Publicación

/dashboard/publicacion

Pantalla de «Resumen final»: estado, errores, advertencias, versión, comprobaciones previas, historial y botón Publicar horario con ventanas de advertencias/bloqueo/éxito.

Estado real de la funciónLa publicación funciona solo con datos locales de demostración (año 2026, «Horario General 2026») y no se comunica con el servidor: publicar aquí no cambia el estado del horario real ni habilita el informe «publicado». Consulta el informe de hallazgos.

14. Auditoría

/dashboard/auditoria

Historial del grupo

  1. Año lectivo y Grupo.
  2. Tipo: Asignación académica o Clase programada; elige el registro concreto.
  3. Ver historial del grupo o Consultar este registro.

Acciones de una cuenta

Selecciona la Cuenta (ej. rector@yarumito.edu.co) → Consultar cuenta. Tabla con Fecha, Acción (Creación/Actualización/Eliminación/Publicación), Registro y botón Ver cambios (valores antes/después).

Ejemplo. Rector · CREATE · Asignación académica · «Álgebra · Grupo 1001» → Ver cambios muestra docente, grupo, horas y estado Borrador.

Solo se auditan asignaciones y clases; crear docentes, aulas o sedes no aparece aquí.

15. Consultas

/dashboard/consultas
  1. Filtros: Año lectivo, Sede, Grupo, Versión (Horario institucional / Horario publicado), Día, Jornada (Regular / Contrajornada), Docente, Estado del horario.
  2. Consultar informe muestra Clases (Día, Hora, Asignatura, Docente, Aula, Estado, Hora extra) y la carga horaria por docente (Ordinarias, Extras, Total).
  3. Descargar PDF o Descargar Excel genera el archivo del grupo.
Ejemplo. 2029 · Sede principal · Grupo 1001 · Horario institucional → Consultar → Descargar PDF.

La versión «Horario publicado» solo funciona si el horario fue publicado en el servidor (hoy no es posible desde la interfaz).

17. Ejemplo completo paso a paso

Objetivo: dejar listo el horario del grupo 1001 (Décimo) del año 2030 con Álgebra impartida por un docente.

  1. Año lectivo → crear 2030 (inicio 2030-01-14, fin 2030-11-29, Activo).
  2. Sedes → Sede Principal ya existente (si no, crearla como principal).
  3. Aulas → sede principal → A-101, tipo Aula, capacidad 35.
